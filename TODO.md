# Work tracker

[GitHub Issues](https://github.com/Lucenx9/codexbar-plasma/issues) is the sole
source of open work, blockers, acceptance criteria, and completion status.
Search existing issues before creating one. Keep progress there; this file
contains no copied task list.

- [Usage and settings](docs/usage.md) describes supported behavior.
- [Documentation index](docs/README.md) links maintained guides and pinned audits.
- [Provider settings proposal](docs/cli-provider-settings-descriptor.md) records
  the proposed upstream contract, which is not a shipped feature.
- [Maintenance workflow](docs/development.md#documentation-and-work-tracking)
  covers issue completion and documentation updates, including direct commits.

Use closing keywords only when all acceptance criteria are met. Historical
audit recommendations describe their comparison date; check current guides and
issues before treating them as unfinished work.
